# Как обращаться к боту: примеры запросов

Эта памятка описывает текущую маршрутизацию. Названия персонажей и алиасы сверяйте с полным [справочником имён](../CHARACTER_ALIASES.md); ограничения по темам — в [правилах персонажей](character_behavior.md). Примеры показывают, кто ответит или что пришлёт, а не точный текст ответа модели.

## Кто отвечает

Короткие продолжения `ещё`, `хочу ещё`, `давай ещё`, `ещё фразу`, `продолжай`, `more`, `I want more`, `one more`, `another one`, `continue`, `go on` продолжают предыдущий запрос того же пользователя в том же чате. Без имени выбирается последний ответивший герой; `Наташа, ещё` выбирает Наташу. Используется её окно контекста (по умолчанию 5 событий), в том числе отметки отправленных стикеров/анекдотов. Если прошлые запрос и ответ не помещаются в окно или окно равно 0, бот уточняет, чего именно ещё. Повторные «ещё» сохраняют связь с исходным запросом. Случайные выборы не гарантируют отсутствие повторов файлов/шуток.

Приоритет маршрутизации такой:

1. Явно названный персонаж отвечает лично. Например, «Наташа, привет» — только Наташа; имя в запросе фиксирует героя.
2. Если имя не названо, но запрос относится к профессиональной теме, отвечает подходящий специалист.
3. При прямом обращении к самому боту без имени персонажа и без специальной темы выбирается один случайный персонаж из семи. Так работают личный чат, `@имя_бота` в группе и ответ на сообщение бота.
4. Командное обращение вызывает сразу нужную группу персонажей.

| Запрос | Кто / что ответит |
|---|---|
| Личный чат: «Привет! Как дела?» | Один случайный персонаж из семи. |
| Группа: `@имя_бота привет` | Один случайный персонаж из семи, если сообщение проходит настройки доступа группы. |
| Ответить на сообщение бота: «А что ты думаешь?» | Один случайный персонаж из семи. |
| «Настя, привет!» / «Nasty, hello!» | Только Настя. |
| «Натусик, привет!» / «Blonde, hello!» | Только Наташа. |
| «Гав, как дела?» / «Woof, hello!» | Только Пёсель. |
| «Мяу, привет!» / «Meu, hello!» | Только Котик. |
| «Стич, привет!» / «Stich, hello!» | Только Стич. |
| «Грут, привет!» / «Grut, hello!» | Только Грут/Клён. |
| «Ракета, привет!» / «Rocket, hello!» | Только Ракета. |

Имя можно поставить в начале или в другом месте фразы. Поддерживаются падежи, регистр, многие английские алиасы, растянутые буквы и часть близких опечаток. Например: «ННННаааастяяя, привет!» позовёт Настю. Отдельное `Wow` не считается именем Пёселя; используйте `Woof`, `Pesel` или «Гав».

## Темы и личные специалисты

Если имя не указано, тематический запрос направляется персонажу, который за него отвечает. Явное имя персонажа сохраняет приоритет и отвечает именно названный герой.

| Тема | Примеры | Маршрут |
|---|---|---|
| Психология, отношения, семейные вопросы, творчество и общие медицинские сведения | «Как справиться с тревогой?», «Помоги написать стихотворение», «Что спросить у врача?» | Наташа |
| Откровенные запросы | Просьба создать взрослый контент | Любой персонаж кратко отказывается и предлагает другую тему. К модели и к шуткам такой запрос не идёт. |
| Растения, выращивание и полив | «Как поливать фикус?» | Грут/Клён |
| Сладости и десерты | «Какой придумать торт?» | Стич |
| Мясные блюда, инженерия | «Как приготовить стейк?», «Помоги с инженерной задачей» | Ракета |
| Собаки, колли и собачий корм | «Почему собака боится грозы?», «Какой корм выбрать для собаки?» | Пёсель (Гав) |
| Кошки и кошачий корм | «Почему кот не ест?», «Какой корм выбрать для кошки?» | Котик (Мяу) |
| Физика, программирование, IT, математика | «Объясни квантовую физику», «Помоги найти ошибку в Python» | Настя |

Например, «Как ухаживать за растением?» без имени позовёт Грута. «Настя, как ухаживать за растением?» оставит ответ Насте. Общий вопрос без имени и без тематического специалиста в личке или при прямом упоминании бота выберет случайного персонажа.

## Позвать нескольких персонажей

Общий вызов отправляет запрос всем семерым. Они отвечают по одному, в случайном порядке; их ответы не перемешиваются с обработкой следующего сообщения.

Примеры общего вызова:

- «Команда А!»
- «Команда, вы тут?» / «Команда, все здесь?»
- «Тима как дела?» / «Тима, ау!» / «Тима, вы тут?»
- «Друзья, на связь!» / «Друзья и подруги, ау!»
- «Банда!» / «Тусовка!» / «Айда все сюда!»
- `Team, are you there?` / `Team, how are you?`

Парный или перечисленный вызов отвечает только названными героями:

- «Ракета и Грут, привет!» — Ракета и Грут.
- «Настя, Наташа и Стич, расскажите шутку» — эти трое.
- «Подруги, ау!» — Настя и Наташа.
- «Ракета и Грут, картинка!» — по стикеру от каждого из двух.

## Анекдоты и юмор

Слова «анекдот», «расскажи анекдот», «юмор», «пошути», «joke» и похожие формулировки вызывают короткий ответ из личного тематического сборника персонажа.

| Запрос | Результат |
|---|---|
| «Расскажи анекдот» / «Юмор» | Один случайный персонаж, если это прямое обращение или личный чат; в группе запрос также может вызвать одного персонажа. |
| «Настя, расскажи анекдот» | Анекдот Насти. |
| «Наташа, юмор» | Анекдот Наташи. |
| «Ракета и Грут, пошутите» | По одному ответу от Ракеты и Грута. |
| «Расскажи анекдот про собак» | Пёсель. |
| «Шутку про кошек» | Котик. |
| «Анекдот про растения» | Грут/Клён. |
| «Шутку про десерт» | Стич. |
| «Юмор про стейк» | Ракета. |

У каждого персонажа собственный список не менее чем из 500 коротких тематических шуток. Общий запрос в группе может сработать без имени; для личного разговора с одним героем назовите его.

## Стикеры и эмоции

| Запрос | Результат |
|---|---|
| «Стикер» / «Картинка» / `sticker` / `picture` / `image` | Один случайный персонаж и один стикер из его активной коллекции. |
| «Настя, стикер» / «Blonde picture» | Случайный стикер только указанного персонажа. |
| «Команда, картинка!» | По одному стикеру от всех семерых последовательно. |
| «Эмодзи» / `emoji` | Один случайный персонаж присылает случайный стикер настроения. |
| «Настя, эмодзи» | Случайная эмоция из набора Насти. |
| «Настя, злись!» / «Настя злая» | Стикер злой эмоции Насти. |
| «Наташа грустит» / «Natasha sad» | Грустный стикер Наташи. |
| «Гав показывает язык» / «Stitch tongue out» | Стикер с языком Пёселя или Стича соответственно. |

Поддерживаемые настроения: грустное, счастливое, злое, агрессивное, доброе, радостное, печальное и показывает язык. Для эмоций распознаются русские и английские варианты, например `sad`, `happy`, `angry`, `aggressive`, `kind`, `joyful`, `sorrowful`, `tongue out`.

Праздничные запросы без имени отправляют по тематическому стикеру от всех семерых: «С Новым годом!», «Рождество!», «С 8 марта!», «С 23 февраля!», «С 1 мая!», «С 9 мая!». Имя ограничивает ответ: «Настя, с Новым годом!» — стикер Насти; «Ракета и Грут, с Рождеством!» — по стикеру от этих двоих. Если у героя для праздника ещё нет подходящего стикера, он отвечает текстом.

## Ответить на предыдущее сообщение и память

Можно нажать «Ответить» на сообщение в Telegram — бот получит контекст исходного сообщения. Также можно сослаться текстом:

- «Посмотри сообщением выше и ответь на него».
- «Ответь на предыдущее сообщение».
- «Ответь на -1 сообщение» — последнее сообщение до текущего.
- «Ответь на -2 сообщение» — через одно.

Настройка **«История ссылок»** задаёт архив для таких обращений: по умолчанию 50 событий, в меню 10–200. Обычный контекст задаётся независимо каждому герою через **«Контекст каждого персонажа»**: по умолчанию 5 сообщений, диапазон 0–65535; например `/context_window Наташа 17`. Ноль отключает его обычную историю.

## Личная память и исправление сведений

Работает при включении памяти у персонажа и пользователя; изначально все выключены.

| Запрос | Результат |
|---|---|
| `/memory` | Сохранённые заметки всех героев только о вас |
| «Наташа память», «Наташа память обо мне», «Наташа /memory» | Её заметки только о вас |
| «Я мужчина», «Я он» | Прямое заявление о мужском роде; приоритет над старой ошибочной записью |
| «Я писал вчера» | Только предположение о роде; подтверждённые данные не меняются |
| «Мне 45 лет» | Возраст с датой сообщения; через полный год от отметки считается 46 |
| «Нет, мне 16» | Замена прежнего возраста и новая дата отсчёта |
| «Мне около 30 лет» | Предположительный возраст с датой; не перекрывает прямое заявление |
| «Теперь я работаю инженером, раньше работал поваром» | Модель обновляет факт о текущей работе, сохраняя дату изменения |

Имя берётся из Telegram, а не из имени персонажа. Для фактов без нового подтверждения прежняя дата сохраняется. Возраст по стилю текста не вычисляется как реальный. `/clear` очищает историю текущего чата, но не личные факты. Отдельное «память» — статистика оперативки, с проверкой системного доступа. Подробнее: [настройка памяти](user_memory.md).

## Анализ последних сообщений

Можно попросить персонажа прочитать последние сообщения этого автора в текущем чате и ответить на вопрос по ним. В анализ попадают только предыдущие сообщения пользователя, который отправил запрос; сообщения других участников группы не смешиваются. Текущий запрос не считается одним из анализируемых сообщений.

- «@имя_бота, проанализируй 30 последних сообщений и определи мой стиль общения» — анализ 30 предыдущих сообщений автора.
- «Настя, прочитай последние 20 сообщений и скажи, какие темы меня волнуют» — тот же анализ, но отвечает Настя.
- «Наташа, проанализируй последние сообщения и оцени психологический возраст автора» — бот случайно выберет число от 10 до 30, возьмёт столько доступных предыдущих сообщений (с учётом лимита в админке) и попросит Наташу дать осторожное, не клиническое впечатление по стилю письма.
- «Проанализируй последние 30 сообщений» — допустим и такой порядок числа и слова «последние».
- `Analyze the last 25 messages` — распознаётся и английская формулировка.

В `/admin` параметр «Анализ истории» задаёт, сколько сообщений автора хранить для такой функции; начальное значение — 100. Диапазон — от 0 до 65 535; 0 отключает анализ. Быстрые варианты доступны кнопками, любое точное значение можно установить командой владельца `/analysis_limit N`, например `/analysis_limit 250`. Если точное количество в запросе не указано, бот выбирает случайное число от 10 до 30; явное число и случайный выбор ограничиваются настройкой. Если доступно меньше сообщений, чем запрошено, анализируются имеющиеся. Очень длинные истории могут быть сокращены до объёма, помещающегося в контекст загруженной модели; в запрос передаются самые новые сообщения, а их фактическое количество указано модели. Новые сообщения накапливаются после включения хранения; старую историю сверх уже сохранённой восстановить нельзя. Обычная настройка памяти диалога остаётся отдельной.

Оценка «психологического возраста» — только приблизительное впечатление от письменной речи, не фактический возраст, диагноз или профессиональная психологическая оценка.

## Язык и характер

Язык ответа каждого персонажа по умолчанию выбирает владелец в `/admin`; по умолчанию — русский. Доступны русский, английский, французский, немецкий, испанский, китайский, японский, корейский, хинди, идиш, белорусский, финский и ирландский.

В сообщении язык можно временно изменить для текущего чата и персонажа:

- «Настя, отвечай на английском».
- «Наташа, answer in French».
- «Грут, отвечай по-немецки».

Характеры персонажей также настраиваются владельцем в `/admin`. Общие стили доступны всем. У Насти дополнительно есть стиль «учительница»: доброе объяснение физики и математики. Кокетливых и откровенных стилей нет. Котик и Пёсель по умолчанию игривые. Настройки характера и языка в админке общие для всех пользователей.

## Статистика компьютера

Статистику видят владелец и пользователи, которым отдельно выдали право на системные сведения. Алиасы можно использовать в вопросе или отправить сами по себе.

| Запросы/алиасы | Что выдаётся |
|---|---|
| «Видеокарта», «покажи GPU», «гпу», «Video», `graphics`, `grapphics`, «3D акселератор», «ускоритель», `nvidia` | Статистика GPU NVIDIA: модель, нагрузка, память и доступные датчики. |
| «Процессор», «камень», `CPU`, «цпу», `processor`, «сколько ядер?» | Сведения о CPU и доступной загрузке. |
| «Оперативка», «оперативная память», «ОЗУ», `RAM`, `DDR`, `memory` | Использование RAM и файла подкачки; доступные характеристики модулей. |
| «Диск», «накопитель», «хранилище», `SSD`, `NVMe`, `HDD`, `drive`, `storage` | Статистика диска моделей `L:` и температура, если датчик доступен. |
| «Характеристики компьютера», «спеки ПК», «весь комп» | Общая сводка GPU, RAM, CPU, Windows и диска `L:`. |
| «Windows», «операционная система», «сборка» | Версия и сборка Windows. |

Владелец выдаёт разрешение командой `/allow_system TELEGRAM_ID`, отзывает — `/deny_system TELEGRAM_ID`; username можно указать ответом на сообщение пользователя. Это отдельное разрешение, оно не открывает обычный доступ к боту.

## Группы, права и очередь

Чтобы бот отвечал в группе, владелец сначала добавляет чат через `/allow_here` или `/allow_chat ID`. Пользователя нужно отдельно допустить через `/allow_user ID`. Режим группы задаётся в `/admin`: `mentions` — ответ на `@username` или reply; `keywords` — также на имена и известные паттерны вызова; `context` — ответ, когда смысл сообщения указывает на обращение; `all` — на каждое сообщение. Для чтения обычных групповых сообщений может потребоваться отключить Group Privacy у BotFather.

Управляющие команды владельца:

- `/allow_here` — разрешить текущую группу; `/deny_here` — запретить ответы, оставаясь в группе.
- `/leave_here` — покинуть текущую группу; `/leave_chat ID` — покинуть указанную группу или канал.
- `/allow_user ID` и `/deny_user ID` — дать или забрать доступ к боту. Для username ответьте командой на сообщение пользователя и укажите `@nickname`.
- `/allow_system ID` и `/deny_system ID` — отдельно дать или забрать доступ к статистике компьютера.
- `/admin` — открыть настройки; `/id` — показать ID чата.
- `/queue_limit 250` — установить точный размер буфера очереди от 1 до 65 536. По умолчанию 50; быстрые значения выбираются в `/admin`. При переполнении старое ожидающее сообщение удаляется молча, а новое остаётся в очереди.

Все команды управления доступны только владельцу по `OWNER_ID`. Параметры админки для персонажей общие для всех пользователей.

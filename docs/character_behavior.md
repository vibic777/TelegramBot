# Ответы персонажей и тематические возможности

Состояние на 2 октября 2026 года. Промпты на английском находятся в `bot/personas.py` (включая `PERSONA_TOPIC_PROMPTS`); язык ответа выбирается отдельно и по умолчанию русский. Базовые контексты Насти и Гава допускают настройку через `.env` и `/admin`. Границы тем добавляются отдельно к системному промпту.

Настя сохраняет уважительный семейный тон при любом стиле: не флиртует, не использует интимные намёки, мат, оскорбления и унизительные прозвища. Игривость и юмор остаются доброжелательными; просьбу унизить собеседника или другого человека она переводит в уважительную формулировку.

## Вызовы и очередь

- «Команда А», «Тима как дела?», «Друзья», «Друзья и подруги ау», «Банда» и «Тусовка» вызывают всех семерых.
- «Ракета и Грут привет» или «Настя, Наташа, Мяу юмор» вызывают только перечисленных персонажей.
- «Подруги ау» без слова «друзья» вызывает только Настю и Наташу.
- Перед ответами список перемешивается, затем герои отвечают по одному. Вызовы в одном чате обслуживаются целиком по очереди; разные чаты независимы.
- «Анекдот», «расскажи анекдот», «юмор» без имени и темы выбирают одного случайного героя. Указанное имя имеет приоритет над автоматическим выбором специалиста.

## Компетенции и юмор

| Герой | Темы | Голос | Личных шуток |
|---|---|---|---:|
| Настя | Физика, математика, IT, программирование, преподавание; также дружеские игры | Русская речь | 600 |
| Наташа | Психология, семья, отношения, литература, стихи, творчество, общая медицинская грамотность, жизнь | Русская речь | 600 |
| Гав | Игры, собаки, уход и собачья еда | Лай и действия, при необходимости ремарка-перевод | 500 |
| Мяу | Игры, кошки, уход и кошачья еда | Мяуканье и действия, при необходимости ремарка-перевод | 500 |
| Стич | Сладости, десерты, весёлые приключения | Понятная смешная речь пришельца | 500 |
| Ракета | Инженерия, изобретения, мясные блюда | Русская речь с характером енота-инженера | 500 |
| Грут | Только растения, ботаника, полив и выращивание | «Я есть Грут» и при необходимости короткое пояснение | 500 |

Личные списки в `bot/persona_jokes.py` дают 3700 уникальных коротких текстов. Это явно шаблонные вариации: для Насти и Наташи по 30, для остальных по 25 тематических предметов обсуждения и 20 авторских сцен, пригодных для всех предметов этого героя. Это не 3700 независимо написанных длинных историй; сходство структуры сохраняется. Тематический запрос выбирает подходящий раздел, а при отсутствии раздела — другую шутку из списка этого же героя. Старый сборник `bot/jokes.py` сохранён как прежний материал и распознаватель тем; активный выбор шуток идет только из личных списков.

Психология без имени направляется Наташе, сладости — Стичу, мясные блюда — Ракете, растения — Груту. Игры без имени направляются Гаву или Мяу. Откровенные запросы любой персонаж отклоняет короткой фразой до обращения к модели и до выбора шутки. Стикер на такой запрос не отправляется.

Профессиональные ответы модели зависят от её качества. Наташа не ставит диагнозы и не назначает лечение. Ограничение остальных тем задано промптом и не является отдельной базой фактов.

## Проверки

Запуск: `.venv/Scripts/python.exe -m unittest discover -s tests -v`.
Тесты используют локальные данные и подменённый Telegram: проверяют ключевые обращения, несколько имён, личный и общий юмор, размер списков, отклонение неподходящих запросов и отсутствие перемешивания двух вызовов одного чата. Живую связку Telegram + LM Studio необходимо проверить после перезапуска бота.

## Праздничные стикеры и имена

Поздравление без имени вызывает всех семерых: каждый последовательно отправляет свой стикер соответствующего праздника, порядок случайный. Одно имя или алиас вызывает только выбранного персонажа; несколько имён — только перечисленных. Поддержаны Новый год, Рождество, 8 марта, 23 февраля, 1 мая, 9 мая. Полный список алиасов, префиксов и шаблонов: [CHARACTER_ALIASES.md](../CHARACTER_ALIASES.md).

## Случайный стикер из коллекции

«Стикер», «картинка», sticker, picture, image без имени выбирают одного из семи персонажей, затем случайный WebP из его активной коллекции. Имя или алиас ограничивает выбор своим персонажем; несколько имён и общий вызов команды отправляют по стикеру от каждого вызванного героя по очереди. Коллекция Насти берётся из nastya_*.webp, коллекции остальных — из их каталогов assets/stickers/characters. Импортные архивы и файлы с пометками adult и flirt исключены из обычного случайного выбора. Праздничные запросы идут в свой обработчик. Откровенный запрос стикер не получает. Все проверки доступа действуют до выбора и отправки.

## Эмоции стикерами

«Эмодзи» или emoji выбирает случайного героя и случайную эмоцию из его набора. Имя героя плюс «эмодзи» выбирает случайную эмоцию только этого персонажа. Имя с названием эмоции — например, «Настя злая», «Ната грустит», «Гав счастливый», «Stitch tongue out» — выбирает соответствующий стикер. Английские названия эмоций тоже распознаются. Если в сообщении несколько имён с командой, каждый вызванный герой отправляет свой стикер по очереди.

Для каждого из семи героев готовы отдельные варианты: грустный, счастливый, злой, агрессивный (комический, без насилия), добрый, радостный, печальный, высунутый язык.

Текущий список 56 эмоциональных стикеров и статус готовности по каждому персонажу: [план стикеров эмоций](emotion_stickers.md).

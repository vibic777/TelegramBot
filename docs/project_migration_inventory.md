# Инвентаризация проектов персонажей

## Обнаруженные соседние папки

- Пустые папки `MaxBot` и `MeuBot` удалены пользователем. `MeuBot` — проект Котика по уточнению пользователя; доступная папка не содержала файлов. Кошачья коллекция WowBot используется для Мяу, но её происхождение из MeuBot не подтверждено.
- `Mafia` — отдельный Node.js-проект Mafia MVP с игровым `bot-dialogue.js`; это не отдельный Telegram-персонаж из общего бота и сюда не переносился.
- Другие локальные проекты не имеют структуры отдельного Telegram-бота по проверенным признакам запуска (`bot/main.py`, `start_bot.bat`, `.env.example` и каталогу `assets/stickers`).

## Условия безопасного удаления

Папки `GrutBot` и `StichBot` содержат только стикерные исходники и материалы, которые уже скопированы; в `StichBot` остаётся отдельно решить вопрос утилиты подготовки. Пустые папки `MeuBot` и `MaxBot` пользователь удалил; если исходники найдутся в другом месте, их можно будет сверить отдельно. `RacketaBot` можно архивировать после сверки его короткого каркаса и настроек. `WowBot` пока удалять нельзя: его Python-код, инструменты и локальное состояние не импортированы и не прошли сверку с общим приложением. `.env`, токены, историю, allow-листы и локальные пользовательские данные не копировать автоматически.

До решения пользователя исходные папки остаются нетронутыми. Сводка полноты художественных наборов и генерации ведётся отдельно в [плане стикеров](sticker_migration_plan.md).

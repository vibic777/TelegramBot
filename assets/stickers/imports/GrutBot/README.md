# Праздничные стикеры Клёна

В каталоге 6 тематических наборов по 9 отдельных изображений (54 SVG-файла). Все изображения имеют холст 512×512, прозрачный фон, единый образ Клёна — нашей версии древесного героя из «Стражей Галактики» с клёновой кроной, белую обводку и не содержат надписей. Фразы для отправки ботом хранятся отдельно в `manifest.json`; соответствия сюжетам и подписи также перечислены в `../../docs/holiday_stickers.md`.

Предварительный просмотр всех рисунков: `index.html`.

Для Telegram уже подготовлены отдельные WebP-файлы 512×512 с прозрачностью. Исходники SVG сохранены рядом и могут использоваться для правок.

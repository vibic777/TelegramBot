# Праздничные стикеры Клёна

Каталог по брифу `docs/holiday_sticker_generation_brief.md`. Персонаж называется Клён: дружелюбный древесный инопланетянин с клёновой кроной. Создано 6 наборов по 9 отдельных сюжетов. Для Telegram готовы WebP 512×512 с прозрачным фоном и белой обводкой; исходные SVG сохранены рядом. Персонаж Клён — наша версия древесного героя из «Стражей Галактики» с клёновой кроной. Надписей внутри рисунков нет; фразы отправляются отдельно через бота и перечислены в `assets/stickers/manifest.json`.

Фразы ниже назначены сюжетам в порядке брифа. Для 9 мая используется сдержанный уважительный тон.
